## Objective
A Python program that takes at least 10 numerical values from the user, analyzes them using NumPy, filters values greater than the mean, and generates a short explanation in simple English using the Groq API.

## Project Files
- `main.py` — Main Python program with modular functions.
- `requirements.txt` — Required Python libraries.
- `.gitignore` — Ensures `.env` and API keys are never uploaded.

## Setup & Usage
1. Install dependencies: `pip install -r requirements.txt`
2. Create a `.env` file and add `GROQ_API_KEY=your_api_key_here`
3. Run the program: `python main.py`
